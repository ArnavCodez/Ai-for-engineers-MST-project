Inside the model, one step at a time

Everything below is the real calculation for the current moment of the replay. Pause the replay to study one moment, or let it run and watch the numbers change.

Twice a second the motor controller measures these eight signals. They are all the model gets. The bar shows where each value sits between the lowest and highest value in our 63 training sessions.

The winding temperature itself is not an input: that is what we estimate. The magnet, tooth and yoke temperatures of the test bench are also left out, because a motor without a winding sensor would not have them either and they would give the answer away.

We add five features from basic motor physics, so the model does not have to discover them on its own.

The current flowing through the copper heats it by I²R, so the square of the current magnitude is the copper loss up to a constant. The electrical and mechanical power tell the model how hard the motor is working.

Copper heats up and cools down slowly. In our exploration the winding temperature followed a change in current about 2.5 minutes later. A model that only sees the present moment cannot know how long the motor has been working hard.

So for eight signals we keep running averages over the last 1, 5, 15 and 45 minutes, 32 features in all. Each one is updated twice a second:

new average = old average + α × (new value − old average), with α = 2 ÷ (span + 1)

The span is counted in samples: 1 minute is 120 samples, so α = 2 ÷ 121 = 0.0165. The 45-minute average moves the slowest. Removing these 32 features raised our cross-validation error from 4.92 to 13.18 °C.

All 32 memory features right now

The 45 inputs come in very different units: volts, amperes, rpm, watts and degrees. Before the network sees them, each one is put on a common scale: z = (value − training mean) ÷ training standard deviation.

So 0 means a typical value from training, +2 means two standard deviations above it. Orange bars are above the training mean, blue bars below. Move the mouse over a bar to see the feature, its raw value and its scaled value.

About the data and the project

The dataset

The model

Our final model is a small neural network (an MLP) with two hidden layers of 64 and 32 neurons, 5,057 learned numbers. We compared nine models with 5-fold cross-validation grouped by session and picked the MLP because it had the lowest cross-validation error. Ridge, a linear model, is shown for comparison.

The models were trained in Python with scikit-learn. Everything on this page runs on your own computer, with no server.
